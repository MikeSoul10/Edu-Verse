# Guía de Modelos de IA Gratuitos en OpenCode

## Resumen de Modelos Disponibles

| Modelo | Variantes | Mejor para |
|--------|-----------|------------|
| **Space Bunny Free** | low, medium, high, xhigh, max | Código complejo, frontend, rediseños |
| **Muse Spark 1.3 Free** | minimal, low, medium, high, xhigh | Tareas de código detalladas |
| **Nemotron 3.5 Lightning Free** | - | Tareas rápidas, iteraciones simples |
| **MiMo-V2.6-Flash Free** | - | Pruebas rápidas, consultas simples |
| **Ling 3.0 Flash Fin Free** | - | Tareas básicas |
| **LongCat 2.5 Preview Free** | - | Conversaciones generales, planificación |
| **Big Pickle** | - | Tareas variadas |

---

## Recomendaciones por Tipo de Tarea

### Frontend / React / JSX
**Recomendado:** Space Bunny Free (high)
- Escribir componentes JSX complejos
- Manejar estado React, hooks, sockets
- Crear animaciones CSS y transiciones
- Rediseñar interfaces completas

### Backend / APIs / Bases de Datos
**Recomendado:** Space Bunny Free (high) o Muse Spark 1.3 (high)
- Diseñar APIs REST
- Consultas SQL complejas
- Manejo de autenticación y seguridad

### CSS / Animaciones / Diseño Visual
**Recomendado:** Space Bunny Free (high)
- Crear animaciones keyframes
- Diseñar layouts responsive
- Implementar glassmorphism, gradientes, sombras

### Planificación / Arquitectura
**Recomendado:** LongCat 2.5 Preview Free (actual)
- Discutir planes de trabajo
- Analizar código existente
- Tomar decisiones de arquitectura

### Pruebas Rápidas / Iteraciones Simples
**Recomendado:** MiMo-V2.6-Flash Free o Ling 3.0 Flash Fin Free
- Cambios pequeños de código
- Correcciones rápidas
- Consultas simples

## Tabla Rápida de Decisión

| Si necesitas... | Usa... |
|-----------------|--------|
| Rediseñar un componente complejo | Space Bunny (high) |
| Escribir mucho código nuevo | Space Bunny (high) |
| Planificar o analizar código | LongCat 2.5 Preview Free |
| Cambios rápidos y simples | MiMo-V2.6-Flash Free |
| Animaciones CSS detalladas | Space Bunny (high) |
| Debugging complejo | Muse Spark 1.3 (high) |

---

## Notas

- **high** suele ser el punto óptimo entre velocidad y calidad
- **xhigh/max** es para tareas muy complejas que requieren mucho razonamiento
- **Flash** models son rápidos pero menos detallados
- Todos los modelos son **gratuitos** en OpenCode
